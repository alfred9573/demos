# Demos

Demos públicas para clientes, servidas con GitHub Pages.

- `barberia/`: asistente de citas por WhatsApp, página web de ejemplo,
  paquetes y calculadora.

Aquí solo va lo que puede ver el cliente. Las fuentes, guiones y márgenes
viven en el repo privado `automatizaciones`; cada `index.html` de aquí es
una copia de `proyectos/<cliente>/sitio/index.html`.
